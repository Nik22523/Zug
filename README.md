#Zug

Ein kleines Java-Projekt zur Simulation eines Zuges mit verketteten Wagen.

## Beschreibung
Der Zug besteht aus mehreren Wagen, die als **verkettete Liste** implementiert sind.  
Es können Wagen hinzugefügt, entfernt und gezählt werden.

##Features
- Wagen anhängen (iterativ & rekursiv)
- Wagen entfernen
- Anzahl der Wagen bestimmen
- Zugstruktur ausgeben

##Starten

```bash
javac *.java
java ZugTest
